## What it does

Ranks pre-token protocols by implied token value, so a farmer can decide where a deposit is actually worth the gas:

- **198-row board** (`board.json`) — 40 watchlist + 138 early sub-$50M + 20 above-floor parent-linked protocols, ranks 1–198, every row with an implied value and a 6-step costed farm plan.
- **Fitted model, not a flat multiple** (`lib/model.ts`, `radar-11-fitted`) — Stage-1 Huber IRLS valuation (`delta=1.0`, `ridgeVec=[0, 1, 20, 50, 50, 150]`, train-fold `y`-winsor `[p5,p95]` before Huber & CatRes, plus undated inferred age/era from first TVL>0 epoch in `data/first-tvl-epoch.json` for the 32 undated live calibration peers only — dated peers and rankable pre-token rows keep authoritative snapshot `listed_at`: TVL size elasticity `−0.4308` pre-2023/undated + `−0.1617` post-`2023-01-01` = `−0.5925` post-2023, standardized 180-day log TVL growth `g180` slope `−0.0487` at `r=50`, `g180×chains^0.6` breadth slope `−0.0807` at `r=50`, `chain_g180×log1p(ageEff)` slope `−0.0922` at `r=150`, base multiple `0.2195x` at `$50M`, shrunk category residuals `n>=5, k=12`) + **Stage-2 zero-intercept 5-term Huber IRLS** (`delta=1.0`, `iters=30`, `ridge=[5, 50, 50, 50, 300]` on Stage-1+CatRes train residuals): multi-chain negative divergence `−min(0, g180 − chain_g180)²` (`chains > 1`, `r=5`, slope `+0.2581`), fold-aware `[p5,p95]`-winsorized `z(log(revenue_180d_sum / tvl))` (`r=50`, slope `+0.0532`, `n=68` non-null, `null -> 0`), fold-aware `z(log(fees_30d_sum / fees_180d_sum))` (`r=50`, slope `+0.1220`, `n=77` non-null, `null -> 0`), fold-aware `z(sign(revenue_365d_sum) × log1p(|revenue_365d_sum| / tvl))` (`r=50`, slope `+0.0969`, defined for all `n=119` peers including negative/zero revenue, no winsor), and fold-aware `z(revenue_180d_sum / fees_180d_sum)` (`takeRate180`, `r=300`, slope `−0.0158`, `n=80` non-null, no winsor, `null -> 0`) × L2 logistic 2-year token-launch odds (unchanged from Rev4: listed age in linear years + category token rate `k=16` + TVL + chains + standardized `g180` slope `−0.3086`, `logit_ridge=3.0`). ## Run it

```sh
node main.ts
```

Node 22+, zero dependencies, zero runtime network, deterministic — two fresh runs are byte-for-byte identical (~1.9 s). Output goes to `/output` (`board.json`, `data.js`, `dossier.json`, screenshots).

## Layout

- `main.ts` — entrypoint; reads the kit snapshot and optional offline `data/history.json` + `data/history-fees.json` + `data/first-tvl-epoch.json`, writes `/output`
- `lib/model.ts` — valuation + odds + farm-verdict engine (zero filesystem reads on import)
- `data/history.json` — baked offline DeFiLlama 180-day TVL growth (`g180` + primary-chain `chain_g180`, truncated `<= 2026-11-14`, unchanged from Rev5–Rev10)
- `data/history-fees.json` — baked offline DeFiLlama daily fees & revenue for all 758 snapshot slugs (strictly truncated `<= 2026-11-14` epoch `1794614400`, zero look-ahead, unchanged from Rev8–Rev10)
- `data/first-tvl-epoch.json` — baked offline DeFiLlama first TVL>0 Unix epoch (`<= 1794614400`) for the 32 undated live valuation peers
- `dashboard/` — static dashboard (`index.html`, `app.js`, `app.css`, `0-model.js`)
- `screenshots/` — 3 real headless-Chromium renders of the live dashboard (`1280×800`, `1280×894`, `1280×979`; palette-optimized `348.6 KB` / `340.5 KiB` total)
- `scripts/heldout.mjs` — walk-forward / leave-one-out ablation tests (10/10 pass)
- `scripts/fetch-history.mjs` — build-time DeFiLlama daily TVL reducer that generated `data/history.json`
- `scripts/fetch-fees.mjs` — build-time DeFiLlama daily fees/revenue fetcher & point-in-time truncator that generated `data/history-fees.json`
- `vendor/makefun-board.ts` — kit board builder (unmodified)
- `STATE.md` — build log, validation numbers, revision history
